Build (verified ✅)

export ANDROID_HOME=/usr/local/lib/android/sdk
cp .env.example .env   # set GEMINI_API_KEY
# debug.keystore already included for local builds
gradle :app:assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk (28 MB)

Verified: assembleDebug succeeds on JDK 17, compileSdk/targetSdk 36, minSdk 24, package com.aistudio.srtplayer.qxpvlt v1.0.

Run in Android Studio

1. Open this folder in Android Studio
2. Create .env with GEMINI_API_KEY (see .env.example)
3. Remove debug signingConfig line per README step 5 (AI Studio only)
4. Run on emulator / device
